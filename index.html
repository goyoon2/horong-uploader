Horong Uploader

A private command-line tool that publishes one creator's own videos to that creator's own channel.

What it is

Horong Uploader is a small command-line program used by a single person, the operator of the Horong channel, to upload videos that the operator made to the operator's own YouTube channel. It is not a public service: nobody else can sign in to it, and it has no user accounts.

What it does

  • Uploads a finished video file to the operator's own channel.
  • Sets the title, description (including chapter timestamps) and tags that the operator wrote.
  • Uploads the Korean subtitle file (.srt) for that video.
  • Sets the thumbnail image for that video.

It does this through YouTube API Services (the YouTube Data API v3). It does not read, collect or store data about other channels, viewers or any other person.

How access works

The operator signs in once with the Google Account that owns the channel and grants the tool permission to upload videos and manage captions. The permission can be removed at any time on the Google Account permissions page.
