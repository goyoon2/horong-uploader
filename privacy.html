Privacy Policy

Effective 6 October 2026

Horong Uploader ("the tool") is a private command-line program used only by its operator to upload the operator's own videos to the operator's own YouTube channel. This policy explains what the tool accesses and what it keeps.

Use of YouTube API Services

The tool uses YouTube API Services (the YouTube Data API v3) to upload videos, captions and thumbnails. Because it uses YouTube API Services, the YouTube Terms of Service apply to its use, and data handled through those services is also subject to the Google Privacy Policy.

Who uses the tool

Only the operator. The tool has no sign-up, no user accounts and no public interface. It does not collect personal information from visitors to this website or from any other person.

Information the tool accesses

  • Authorization credentials. When the operator signs in with Google, the tool receives OAuth tokens that let it upload videos and manage captions on the operator's own channel.
  • Upload results. After an upload, the tool receives the identifier and status of the video it has just uploaded.

The tool does not request or read data about other channels, viewers, comments, subscribers or analytics.

How the information is used

The credentials are used only to send the operator's own video file, title, description, tags, captions and thumbnail to YouTube. The upload result is shown to the operator so that the operator can open the video.

Storage and sharing

The OAuth tokens are stored in a file on the operator's own computer. They are not sent to any server other than Google's, and they are not shared with, sold to or disclosed to any third party. The tool has no server and no database.

Cookies and tracking

The tool does not place cookies and does not use advertising or analytics trackers. This website is a set of static pages and does not set cookies of its own.

Deleting stored data and revoking access

The operator can delete the stored tokens at any time by deleting the token file from the computer. Access can also be revoked on the Google Account permissions page; once revoked, the stored tokens stop working. The tool keeps no other data obtained through YouTube API Services.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.
